# 个人介绍网站 · 张宇桐

纯静态个人展示站：https://zyttt2007.github.io/
数字经济专业大二在读，无后端、无登录，浏览器打开即可浏览。

## 内容怎么改

打开网站，点左下角「✎ 编辑内容」（或访问 `?edit=1`）进入编辑模式：点文字即可修改，
卡片可编辑 / 删除 / 排序，每个列表末尾可以新增条目；项目卡片支持两个图片字段
（`photo` 真实摄影配图、`image` 网站界面截图）。改动自动保存在当前浏览器（localStorage），
刷新后保留。站点默认内容升级时，旧草稿会自动备份、不再覆盖新页面。

要让公网所有人都看到新内容：在编辑条点「导出 index.html」，用下载的文件替换本仓库
根目录的 index.html。导出的 HTML 里静态内容和内嵌数据会一起更新，不执行 JavaScript
也能读到新内容。「导出数据 / 导入数据」用于备份与换设备；「恢复默认」回到初始内容。

## 图片说明

- `images/photo-*.jpg`：来自 Unsplash 免费图库的真实摄影照片（旧书、食材砧板、陶艺拉坯、手冲咖啡）
- `images/img-*.jpg`：青苔笔记 / 灶台问答 / 一枚手作三个线上站点的真实界面截图
- 「关于我」板块使用 `photo-me.jpg` 真实照片，全站没有卡通插画

图片全部本地托管，不依赖外部 CDN。

## 本地重建

`site-data.json` 是默认数据源，`template.html` 是页面骨架，运行 `python build.py`
可重新生成 `index.html`（生成的页面本身是完整静态 HTML，不依赖脚本也能阅读）。
`editor.js` 提供网页内编辑功能，`style.css` 含编辑模式样式。

推送到 main 会由 `.github/workflows/pages.yml` 自动部署到 GitHub Pages。
